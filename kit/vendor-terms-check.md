# Vendor terms check (Level 1)

Five questions to answer from each AI vendor's own terms for the plan you use. Check the plan carefully: free, personal and business plans of the same tool often have different terms. Answer 1 to 3 first; they set your ratings. Answers 4 and 5 are for the record and can wait up to 30 days.

**Tool and plan:** ____________________ **Checked by and date:** ____________________

| Question | Answer | Where it says so (document, section, date) | Feeds |
| --- | --- | --- | --- |
| 1. Does the vendor use our inputs or outputs to train its models, including "de-identified" data? Can we turn that off, and is it off? | | | Retention (Q2); Contract (Q3) |
| 2. How long does the vendor keep our prompts, files and outputs, and can our admin change or delete them? | | | Retention (Q2) |
| 3. Is there a data processing agreement (DPA) that covers this plan? | | | Contract (Q3) |
| 4. Which other companies (subprocessors, model providers) receive our data? | | | Record only; within 30 days |
| 5. Where is our data processed and stored? | | | Record only, unless a client contract restricts location |

**Notes for the person checking**

- Use the vendor's contract documents, read on the vendor's own website: terms of service, DPA, AI or data-use terms. A marketing page or help article is a lead, not evidence. A copy someone emails you is checked against the published one.
- Quote the sentence that answers the question. If no document answers it, write "not stated" and treat it as the worse answer when you score.
- A certificate counts only if it names this product and this vendor entity, and is in date.
